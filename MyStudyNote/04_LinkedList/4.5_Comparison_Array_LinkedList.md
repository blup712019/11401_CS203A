# Comparison: Array vs. Linked List

## 核心差異一句話
- **Array**：連續記憶體，用 index 算位址，快在存取  
- **Linked List**：不連續節點，用 pointer 串接，快在改結構 

## 結構比較

| 面向 | Array | Linked List |
|---|---|---|
| 記憶體 | 連續 | 不連續 |
| 存取方式 | index | pointer |
| Random Access | O(1) | O(n) |
| 插入 / 刪除（中間） | O(n) | O(1)\* |
| Cache 友善 | 高 | 低 |
| 記憶體額外成本 | 低 | 高（pointer） |

## 操作重點

### Access
- Array：`a[i]` → **O(1)**
- Linked List：必須從 head 走 → **O(n)**

### Insert / Delete
- Array：需要 **shift**
- Linked List：只改 **pointer**

## 為什麼實務常選 Array？
- Cache locality 好
- CPU 預取有效
- Big-O 一樣時，Array 通常更快

## 什麼時候選誰？

### 選 Array
- 常用 index
- 大量讀取 / iteration
- 效能敏感

### 選 Linked List
- 頻繁插入 / 刪除
- 已持有 node
- 需要 splice / merge
