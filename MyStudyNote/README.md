## 主要的筆記結構

### 每個主題通常會放在一個資料夾中（例如 `07_Tree`、`08_Heap`），並以 `README.md` 作為該章的入口。

### 我整理筆記時常用的章節模板（不一定每章都包含全部）：
- **Core / Introduction**：定義、直覺、常見誤解、重要術語
- **ADT / Operations**：抽象資料型別與基本操作（語意、流程、易錯點）
- **Representation**：常見實作表示法與其取捨
- **Complexity**：時間/空間複雜度、最壞/平均/攤提、形狀或資料分佈的影響
- **Pros & Cons**：適用情境、限制、工程實務的注意事項
- **Variations**：常見變形與何時該用哪一種
