
# CPE 練習紀錄 

本資料夾用來整理我在準備 **CPE（Collegiate Programming Examination）** 時的練習題目，依主題分類，方便學習與複習。

### 1_basic
基礎題型練習，包含：
- 基本輸入輸出
- 字串處理
- 簡單模擬與邏輯判斷等

### 2_DS（Data Structure）
資料結構相關題目：
- Array
- Stack / Queue
- Set / Map
- 其他常見資料結構應用

### 3_algorithm
演算法核心題目：
- 搜尋與排序
- 貪婪演算法（Greedy）
- 遞迴、Divide and Conquer
- DP

### 4_math
數學相關題目：
- 數論
- 質數
- GCD / LCM
- 基本排列組合
- 構造觀察

### 5_graph
圖論相關題目：
- BFS / DFS
- 最短路徑
- 圖的連通性問題

## 練習目標
- 熟悉 CPE 常見題型
- 提升解題速度與正確率

## 備註
- 題目來源以 CSES / UVa 為主  
- 部分註解由AI輔助完成
