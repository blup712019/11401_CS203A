## UVa 10048 - Audiophobia
- 類型：Graph / Floyd-Warshall（Minimax）
- 解法思路：
  1. 對每一對 (i, j) 定義 dist[i][j]：從 i 到 j 的路徑中，「最大邊權」的最小可能值（minimize the maximum edge）。
  2. 初始化：
     - dist[i][i] = 0
     - 若有邊 i-j 權重 w，dist[i][j] = dist[j][i] = min(原本, w)
     - 其他為 INF
  3. Floyd-Warshall 轉移（minimax 版本）：
     - dist[i][j] = min(dist[i][j], max(dist[i][k], dist[k][j]))
  4. 查詢 (a, b)：
     - 若 dist[a][b] 是 INF → `no path`
     - 否則輸出 dist[a][b]
- 複雜度：O(C^3)，C ≤ 100 可行

### 參考實作

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int C, S, Q;
    int tc = 1;
    while (cin >> C >> S >> Q) {
        if (C == 0 && S == 0 && Q == 0) break;

        const int INF = 1000000000;
        vector<vector<int>> dist(C + 1, vector<int>(C + 1, INF));
        for (int i = 1; i <= C; i++) dist[i][i] = 0;

        for (int i = 0; i < S; i++) {
            int a, b, w;
            cin >> a >> b >> w;
            dist[a][b] = min(dist[a][b], w);
            dist[b][a] = min(dist[b][a], w);
        }

        for (int k = 1; k <= C; k++) {
            for (int i = 1; i <= C; i++) {
                for (int j = 1; j <= C; j++) {
                    int via = max(dist[i][k], dist[k][j]);
                    dist[i][j] = min(dist[i][j], via);
                }
            }
        }

        cout << "Case #" << tc << "\n";
        for (int i = 0; i < Q; i++) {
            int a, b;
            cin >> a >> b;
            if (dist[a][b] >= INF) cout << "no path\n";
            else cout << dist[a][b] << "\n";
        }

        tc++;
        if (!(C == 0 && S == 0 && Q == 0)) cout << "\n";
    }
    return 0;
}
