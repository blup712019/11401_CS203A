## UVa 459 - Graph Connectivity
- 類型：Graph / DFS / Connected Components
- 解法思路：
  1. 每組測資先讀到最大的節點字母（例如 'E' 代表節點 A~E）。
  2. 讀取邊（每行兩個字母），直到空行或 EOF。
  3. 用 DFS 從每個尚未訪問的節點出發，將同一個連通分量內的點全部標記。
  4. DFS 啟動的次數就是連通分量數量。
- 複雜度：
  - 建圖 O(E)
  - DFS O(V + E)

### 參考實作

```cpp
#include <iostream>
#include <vector>
#include <map>
#include <string>

using namespace std;

map<char, vector<char>> map1;
map<char, int> ck;

void dfs(char current) {
    ck[current] = 1;
    for (auto& a : map1[current]) {
        if (ck[a] == 0) {
            dfs(a);
        }
    }
}

int main() {
    int n;
    cin >> n;
    string t;
    int ans;

    for (int i = 0; i < n; i++) {
        ans = 0;
        map1.clear();
        ck.clear();

        cin >> t;
        cin.ignore();

        for (int j = 'A'; j <= t[0]; j++) ck[(char)j] = 0;

        while (getline(cin, t) && !t.empty()) {
            map1[t[0]].push_back(t[1]);
            map1[t[1]].push_back(t[0]);
        }

        for (auto& a : ck) {
            if (a.second == 0) {
                ans++;
                dfs(a.first);
            }
        }

        cout << ans << endl;
        if (i != n - 1) cout << endl;
    }
}
