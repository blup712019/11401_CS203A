## UVa 441 - Lotto
- 類型：Backtracking / Combination
- 解法思路：
  1. 每組輸入給 K 個數字，要輸出所有「選 6 個」的組合，並保持輸入順序（遞增索引）。
  2. 用 DFS 回溯：每次從當前索引之後挑下一個數字加入組合，直到組合長度為 6 就輸出。
  3. 兩組測資之間要輸出空行（最後一組不需要額外空行）。
- 複雜度：
  - 組合數 C(K,6)，每組輸出 6 個數

### 參考實作

```cpp
#include <iostream>
#include <vector>
using namespace std;

int k;
vector<int> a;
vector<int> pick;

void dfs(int idx) {
    if ((int)pick.size() == 6) {
        for (int i = 0; i < 6; i++) {
            if (i) cout << " ";
            cout << pick[i];
        }
        cout << "\n";
        return;
    }
    for (int i = idx; i < k; i++) {
        pick.push_back(a[i]);
        dfs(i + 1);
        pick.pop_back();
    }
}

int main() {
    bool first = true;

    while (cin >> k && k) {
        a.assign(k, 0);
        for (int i = 0; i < k; i++) cin >> a[i];

        if (!first) cout << "\n";
        first = false;

        pick.clear();
        dfs(0);
    }
    return 0;
}
