## UVa 543 - Goldbach's Conjecture
- 類型：Math / Prime / Sieve
- 解法思路：
  1. 題目要對每個輸入 n（偶數）找出兩個質數 a、b 使得 n = a + b。
  2. 先用篩法預處理 1,000,000 以內所有質數。
  3. 對每個 n，從 a = 2 開始掃到 n：
     - 若 a 與 n-a 都是質數，就輸出 `n = a + (n-a)` 並停止。
  4. 若找不到則輸出 `Goldbach's conjecture is wrong.`
- 複雜度：
  - 篩法 O(N log log N)
  - 每次查詢最壞 O(N)（N=1e6)

### 參考實作

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    const int MAXN = 1000000;
    vector<bool> isPrime(MAXN + 1, true);
    isPrime[0] = false;
    isPrime[1] = false;

    for (int i = 2; 1LL * i * i <= MAXN; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= MAXN; j += i) isPrime[j] = false;
        }
    }

    int n;
    while (cin >> n && n) {
        bool ok = false;
        for (int a = 2; a <= n; a++) {
            if (isPrime[a] && isPrime[n - a]) {
                cout << n << " = " << a << " + " << (n - a) << "\n";
                ok = true;
                break;
            }
        }
        if (!ok) cout << "Goldbach's conjecture is wrong.\n";
    }
    return 0;
}
