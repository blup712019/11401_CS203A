## UVa 10106 - Product

**類型**：Math / Big Integer

**解法思路**：

- 兩個輸入數字長度可達上千位，無法使用內建整數型別
- 使用字串讀入，轉為反向儲存的整數陣列
- 以模擬直式乘法進行
- 最後處理進位並輸出去除前導零的結果

**複雜度**：

- 時間：O(n × m)
- 空間：O(n + m)

### 參考實作

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

int main() {
    string a, b;
    while (cin >> a >> b) {
        if (a == "0" || b == "0") {
            cout << 0 << '\n';
            continue;
        }

        int n = a.size();
        int m = b.size();
        vector<int> x(n), y(m);

        for (int i = 0; i < n; i++) x[i] = a[n - 1 - i] - '0';
        for (int i = 0; i < m; i++) y[i] = b[m - 1 - i] - '0';

        vector<int> res(n + m, 0);

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                res[i + j] += x[i] * y[j];
            }
        }

        for (int i = 0; i < n + m - 1; i++) {
            res[i + 1] += res[i] / 10;
            res[i] %= 10;
        }

        int idx = n + m - 1;
        while (idx > 0 && res[idx] == 0) idx--;

        for (int i = idx; i >= 0; i--) cout << res[i];
        cout << '\n';
    }
    return 0;
}
