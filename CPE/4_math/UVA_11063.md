## UVa 11063 - B2-Sequence

**類型**：Math / Set / Checking

**解法思路**：

- 先檢查序列是否皆為正整數且嚴格遞增
- 用集合記錄所有 i ≤ j 的 a[i] + a[j]
- 若出現重複的和，則不是 B2-Sequence
- 依題目格式輸出，每筆測資後要空一行

**複雜度**：

- 時間：O(n^2)
- 空間：O(n^2)

### 參考實作

```cpp
#include <iostream>
#include <vector>
#include <set>
using namespace std;

int main() {
    int n;
    int tc = 1;
    while (cin >> n) {
        vector<int> a(n);
        for (int i = 0; i < n; i++) cin >> a[i];

        bool ok = true;

        if (n > 0 && a[0] < 1) ok = false;
        for (int i = 1; i < n; i++) {
            if (a[i] <= a[i - 1]) {
                ok = false;
                break;
            }
        }

        if (ok) {
            set<int> sums;
            for (int i = 0; i < n && ok; i++) {
                for (int j = i; j < n; j++) {
                    int s = a[i] + a[j];
                    if (sums.count(s)) {
                        ok = false;
                        break;
                    }
                    sums.insert(s);
                }
            }
        }

        if (ok) {
            cout << "Case #" << tc << ": It is a B2-Sequence.\n\n";
        } else {
            cout << "Case #" << tc << ": It is not a B2-Sequence.\n\n";
        }
        tc++;
    }
    return 0;
}
```
