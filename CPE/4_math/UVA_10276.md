## UVa 10276 - Hanoi Tower Troubles Again!

**類型**：Math / Greedy / Perfect Square

**解法思路**：

- 依題意用「永遠放最左邊可放的柱子」的策略會得到最大可放球數
- 可由歸納推得：n 根柱子最多可放的球數為 ⌊(n+1)^2 / 2⌋ - 1

**複雜度**：

- 時間：O(1)
- 空間：O(1)

### 參考實作

```cpp
#include <iostream>
using namespace std;

int main() {
    int t, n;
    cin >> t;
    while (t--) {
        cin >> n;
        cout << (n + 1) * (n + 1) / 2 - 1 << "\n";
    }
    return 0;
}
